# EDAB2724 Assignment 2: Credit Scoring

## Overview
This assignment applies machine learning to predict loan defaults using credit-scoring data, with particular attention to severe class imbalance.

## Key Activities
- Perform Exploratory Data Analysis (EDA).
- Build Logistic Regression, Random Forest and XGBoost models.
- Investigate class imbalance treatment.
- Perform hyperparameter tuning and threshold selection.
- Evaluate models using appropriate classification metrics.
- Interpret results in a credit-risk context.

## Tools and Technologies
Python, Jupyter Notebook, pandas, NumPy, scikit-learn, XGBoost, Matplotlib and Seaborn.

## Learning Outcomes
Gain experience in predictive modelling, model evaluation, class imbalance handling and applying machine learning to financial risk analysis.
